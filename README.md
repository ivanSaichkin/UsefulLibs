# Vector
Some methods from std::vector
#Methods
##Access to the elements
• **at** - provides access to an element by index with verification
• **front** - provides access to the first element
• **back** - provides access to the last element
***
##Working with vector size
• **empty** - checking for emptiness
• **size** - return vector size
• **capacity** - return vector capacity
• **reserve** - reserves the capacity of the vector
***
##Modificators
• **clear** - clears the array and makes it empty
• **pushBack** - adds an element to the end of the vector
• **popBack** - deletes the last element of the vector
• **insert** - inserts an element into a vector by index
• **erase** - deletes an element of the vector by index
• **swap** - swaps the contents of two vectors in places
***
##Iterators
• **begin** - returns a pointer to the null element
• **end** - returns a pointer to the *[size]* element
• **rbegin** - returns a pointer to the element that is the reverse of the null (last)
• **rend** - returns a pointer to the element that is the reverse of the *[size]* element (before null)
